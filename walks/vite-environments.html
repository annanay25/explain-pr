There was always a client, and optionally SSR. They shared too much implicit state: one mental model, two module graphs stuffed into server internals.

The problem: production has more rooms than client and SSR

A modern app is a set of runtimes. Vite 6 makes that set a first-class map instead of a boolean.

Browser

The classic client bundle. Still environment client.

Node SSR

Still environment ssr. No longer the only extra room.

environment Edge A named runtime production already has.

environment rsc Author-defined. Own graph.

React Server Components need a graph that is neither client nor classic SSR. That is the point of a map.
